# Generate Code Availability Protocol

This repository contains all scripts needed to prepare a batch of papers to evaluate using the Code Availability Protocol. Please note that to use the scripts in this repository, you will have to provide your own list of papers and accompanying PDF's. 

## Repository Structure
```
Generate-Code-Availability-Protocol/
├── 1_pdf_to_XML.qmd                    # Step 1: convert your PDFs to TEI-XML via GROBID
├── 2_link_and_keyword_extraction.qmd   # Step 2: parse XML + BibTeX, extract links/keywords, merge into one dataset
├── 3_Generate_coder_batch.R            # Step 3: package PDFs + report + JSON into one folder per coder batch
│
├── R/                                  # Internal helpers — sourced/rendered by the scripts above, never run directly
│   ├── batch_json.R                    # Builds the papers/records JSON a coder uploads to index.html
│   └── report_template.qmd             # Links-and-keywords report template, rendered per batch by script 3
│
├── index.html                          # Coder-facing protocol app (copied into each batch folder)
│
├── all_articles_metadata.bib           # Your BibTeX export (e.g. from Zotero) — input to script 2
├── all_articles.rds                    # Your screening/inclusion decisions — input to script 2
│                                        #   (needs doi_no_slash + included columns)
├── Articles All Records/               # Your PDF corpus, and the XML script 1 generates from it
│   ├── files/                          #   Source PDFs (one subfolder per paper)
│   └── <doi_no_slash>.xml              #   TEI-XML generated by script 1, one per paper
│
├── auto_report_input_data.rds          # Generated by script 2 — merged data script 3 reads (don't edit by hand)
│
└── Batches/                            # Generated by script 3 — one folder + .zip per coder batch (gitignored)
    └── <coder_id>_<firstID>-<lastID>/
        ├── index.html
        ├── papers_batch_<coder_id>.json
        ├── support_file.html
        └── pdfs/
```
